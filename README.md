# Absa-Bank-Financial-Model
3-Statement Financial Model and Investment Memo for Absa Bank Kenya PLC.
This repository contains a fully integrated 3-statement financial model and a supporting investment memo for Absa Bank Kenya PLC, a publicly traded commercial bank.

## 🔍 Project Overview
* **Historical Data:** Model built using 5 years of historical audited financial reports.
* **Forecasting:** Consolidated a 40-line balance sheet into core categories to forecast a 5-year horizon (2026–2030).
* **Key Drivers:**
   * Loan Growth.
   * Cost-to-Income.
   * Cost of Risk.
  
* **Integrity Check:** Linked the Income Statement to the Balance Sheet via Retained Earnings, ensuring the Balance Sheet balances to zero across all forecasted years.
